# Core dependencies for Damanat PMS Video Analytics — CLIENT INSTALL.

# torch + torchreid notes:
#   torchreid (vehicle re-ID model) needs torch + torchvision. We pull them
#   from PyTorch's CPU-only index — without --extra-index-url pip resolves
#   to the GPU build (~2GB) which we don't need on the inference boxes.
#   Order matters: numpy<2 first, then torch/torchvision, then torchreid.
#
# torchreid is technically only required by the TRAINING tools (under
# tools/) and by the legacy fallback ReID path in src/reid_matcher. The
# production engine loads ReID via OpenVINO so torchreid is never called
# at runtime; kept here so the legacy fallback still works if needed.
--extra-index-url https://download.pytorch.org/whl/cpu

# Plate-OCR cross-check (Wave 1 / WS-D). Enabled: OCR is the only modality
# that can name a PARKED car (ReID cannot), so current_plate depends on it.
#
# Requires matching.plate_ocr_model non-empty in config.yaml ("auto" routes to
# the PaddleX cache; a directory pins an explicit PaddleOCR home).
#
# Versions are pinned to the set validated on the dev machine — paddleocr 3.x
# changed the constructor signature and the model-name flags, so a float here
# silently changes which weights load.
#
# The det/rec/angle weights (~20 MB) are NOT downloaded at runtime: the
# Dockerfile warms $PADDLE_PDX_CACHE_HOME at build time so the pod needs no
# internet egress and no writable $HOME. Outside Docker they land in
# ~/.paddlex/official_models/ on the first PlateOCR.read() call.
#   - Models: PP-OCRv5_mobile_det, en_PP-OCRv5_mobile_rec,
#     PP-LCNet_x1_0_textline_ori (pulled by use_angle_cls=True).
#   - On Windows + paddlepaddle 3.x, oneDNN can trip a NotImpl at predict
#     time; the plugin sets FLAGS_use_mkldnn=0 by default to avoid it.
paddleocr==3.5.0
paddlepaddle==3.3.1
paddlex==3.5.2
