# Core dependencies for Damanat PMS Video Analytics — CLIENT INSTALL.
#
# torch + torchreid notes:
#   torchreid (vehicle re-ID model) needs torch + torchvision. We pull them
#   from PyTorch's CPU-only index — without --extra-index-url pip resolves
#   to the GPU build (~2GB) which we don't need on the inference boxes.
#   Order matters: numpy<2 first, then torch/torchvision, then torchreid.
#
# torchreid is technically only required by the TRAINING tools (under
# tools/) and by the legacy fallback ReID path in src/reid_matcher. The
# production engine loads ReID via OpenVINO so torchreid is never called
# at runtime; kept here so the legacy fallback still works if needed.
--extra-index-url https://download.pytorch.org/whl/cpu
